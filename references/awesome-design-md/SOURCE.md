# awesome-design-md (참고 자료)

이 폴더는 **설치형 스킬이 아닌 참고 문서**입니다.
`.claude/skills/` 밖에 있으므로 Claude Code가 스킬로 자동 로드하지 않습니다.
필요할 때 특정 `design-md/<사이트>/DESIGN.md`를 직접 지정해서 읽게 하세요.

- 출처: https://github.com/voltagent/awesome-design-md
- 커밋: `f696123` (2026-09-21)
- 라이선스: MIT (`LICENSE` 참고)
- 포함: `README.md`, `LICENSE`, `design-md/` (74개 사이트, 각 `DESIGN.md` + `README.md`)
- 제외: `.github/`, `.gitignore`, `CONTRIBUTING.md`

사용 예:

```
references/awesome-design-md/design-md/vercel/DESIGN.md 를 참고해서 이 페이지의 색·타이포 톤을 맞춰줘
```

각 `DESIGN.md`는 실제 웹사이트의 디자인 언어를 분석한 문서입니다.
프로젝트 고유의 디자인 방향을 정할 때 참고용으로만 쓰고, 특정 브랜드를 그대로 흉내 내지 않도록 주의하세요.
